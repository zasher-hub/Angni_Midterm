# Mind Your Botness

## Privacy-Focused Social Media Platform

### Project Overview

Mind Your Botness is a privacy-focused social media platform prototype developed using HTML, CSS, and Vanilla JavaScript. The platform allows users to connect, share ideas, and express themselves freely without worrying about AI systems spying on them or collecting their personal data.

This project was created as a frontend-only application, meaning no backend, database, or external APIs were used.

---

## Project Name

**Mind Your Botness**

### Slogan

> Ryan Gosling respects your privacy. AI should too.

---

## Project Objectives

- Create a multi-page social media application.
- Promote privacy and data protection.
- Demonstrate HTML, CSS, and JavaScript skills.
- Allow users to create and view posts.
- Encourage freedom of expression in a secure environment.
